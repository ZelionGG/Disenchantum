# Disenchanter

Queue bag items and disenchant them from a single secure button. World of Warcraft Retail (`Interface 120100`).

Blizzard requires a hardware click for each Disenchant cast (spell `13262`). This addon builds the list; you click (or keybind) once per item.

## Usage

- `/de` or `/disenchanter` opens the window.
- Open **Filters** to choose quality and expansion, click items or **Add all**, then click **Disenchant**.
- Drag items from bags onto the window to enqueue them.
- Drag queued rows to reorder. Bind **Disenchant next queued item** in Key Bindings.

## Install

Extract into `Interface/AddOns` and `/reload`.
